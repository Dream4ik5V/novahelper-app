Установка без SmartScreen

Скачайте маленький загрузчик — он сам возьмёт установщик с GitHub и запустит его. Браузер не помечает установщик, поэтому Windows не показывает SmartScreen.

⬇ Скачать загрузчик и установить Прямой установщик (может быть SmartScreen)
Загрузчик скачивается один раз. Если Windows спросит «Открыть файл?» — нажмите «Запустить».

Способ в одну команду

Вставьте команду в PowerShell — она скачает и запустит установщик без метки браузера.

$u='https://github.com/Dream4ik5V/novahelper-app/releases/latest/download/NOVA-RP-Wiki-Setup.exe'; $f="$env:TEMP\NOVA-RP-Wiki-Setup.exe"; Invoke-WebRequest $u -OutFile $f; Start-Process $f

Как установить

  1. Нажмите «Скачать загрузчик» выше.
  2. Откройте скачанный NOVA-RP-Установить.bat (если появится окно «Открыть файл?» — «Запустить»).
  3. Дождитесь загрузки установщика (133 МБ) — он запустится сам.
  4. Выберите папку установки и нажмите «Установить». По желанию оставьте галочки ярлыков.
  5. Готово: приложение запустится, а дальше обновления приходят сами.
